# ضبط‌کننده صدای داخلی — نسخه ۲ (Hardened)

## نصب و اجرا
1. پروژه را در Android Studio (Hedgehog یا جدیدتر) با "Open" باز کنید.
2. Gradle sync را بگذارید کامل شود (نیاز به اینترنت برای دانلود وابستگی‌ها).
3. روی دستگاه/امولاتور با Android 10 (API 29) به بالا اجرا کنید (برای گرفتن صدای internal بهتر Android 13+ باشد).
4. `Run ▶` یا `./gradlew assembleDebug` برای ساخت APK.

## چه چیزی نسبت به نسخه قبل عوض شده؟

### پایداری / رفع باگ
- ثبت `MediaProjection.Callback` — قطع شدن سیستمی ضبط دیگر باعث کرش نمی‌شود.
- کل مسیر شروع ضبط (`startRecordingSafely`) در try/catch است؛ هر خطا toast می‌دهد و سرویس تمیز بسته می‌شود.
- بوکمارک‌ها الان واقعاً در دیتابیس ذخیره می‌شوند (`RecordingDao.updateBookmarks`) و با تپ روی هر آیتم لیست قابل مشاهده‌اند.
- **باگ ADTS header**: در نسخه قبل freqIdx/chanCfg هارد-کد بودن (همیشه 48kHz استریو) و اگر کیفیت کم/متوسط انتخاب می‌شد فایل خروجی خراب/غیرقابل‌پخش بود. الان بر اساس `RecordingQuality` واقعی محاسبه می‌شود.
- حذف کامل `bindService`/`ServiceConnection` که منبع باگ‌های sync نشدن UI و کرش unbind بود؛ به‌جایش `StateFlow` در companion object سرویس.
- migration واقعی Room (v1→v2) به‌جای `fallbackToDestructiveMigration` — رکوردهای قدیمی پاک نمی‌شوند.
- چک فضای ذخیره‌سازی (حداقل ۵۰ مگابایت) قبل از شروع ضبط.
- WakeLock جزئی حین ضبط تا برخی گوشی‌ها (شیائومی/سامسونگ) سرویس را در حالت خواب نکشند + راهنمای غیرفعال‌سازی بهینه‌سازی باتری.

### قابلیت‌های جدید
- **مکث/ادامه ضبط** (دکمه در اپ + اکشن در نوتیفیکیشن).
- **کیفیت قابل‌تنظیم** (کم/متوسط/بالا) در صفحه تنظیمات.
- **موج صدای زنده** (`WaveformView`) حین ضبط.
- **جستجو و مرتب‌سازی** لیست ضبط‌ها (تاریخ/نام/مدت/حجم).
- **تغییر نام**، **اشتراک‌گذاری** (FileProvider + Intent chooser)، و **نمایش بوکمارک‌ها** از منوی هر آیتم.
- حالت شب (Dark theme) کامل.
- تم‌بندی به `ViewModel` (`RecordingListViewModel`) برای جداسازی منطق از UI.

## محدودیت‌های شناخته‌شده
- ضبط صدای داخلی روی برخی گوشی‌های سامسونگ/شیائومی به‌خاطر محدودیت‌های سازنده ممکن است صدا ندهد یا نیاز به مجوز اضافه سیستمی داشته باشد — این محدودیت پلتفرم اندروید است، نه باگ اپ.
- فرمت خروجی همچنان فقط AAC است (MP3/WAV در این نسخه اضافه نشده).
- تست‌های واحد (`app/src/test`) پوشش پایه دارند؛ تست UI/Instrumented اضافه نشده.

## چک‌لیست تست دستی
- [ ] شروع ضبط → توقف → فایل در لیست ظاهر شود با مدت/حجم درست
- [ ] علامت‌گذاری چند بار حین ضبط → بعد از توقف، تپ روی آیتم → زمان‌ها درست نمایش داده شوند
- [ ] مکث → ادامه → توقف → مدت زمان محاسبه‌شده باید مدت زمان مکث را کم کرده باشد
- [ ] تغییر کیفیت در تنظیمات → ضبط جدید → پخش فایل بدون قطعی/نویز
- [ ] رد کردن دسترسی میکروفون → دکمه ضبط باید toast بدهد نه کرش
- [ ] بستن اپ حین ضبط و بازکردن دوباره → دکمه و وضعیت باید "در حال ضبط" نشان دهند
- [ ] "توقف اشتراک‌گذاری صفحه" از نوار سیستم حین ضبط → سرویس باید تمیز متوقف شود
- [ ] جستجو در لیست + هر ۴ حالت مرتب‌سازی
- [ ] تغییر نام یک ضبط → نام در لیست و در دیالوگ بوکمارک آپدیت شود
- [ ] اشتراک‌گذاری یک فایل → چوزر سیستم باز شود بدون کرش
